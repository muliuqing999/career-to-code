# 人工行为回归情境

每个情境用新的聊天测试。向 AI 提供技能及情境文字，观察实际回复，不事先提供“应该怎么答”。本文件是测试方案，不代表已通过独立模型评测。

## 1. 不知道方向

输入：“我研一，计算机相关，本科主要应付考试，想在家附近找工作，每周十小时，但不知道适合什么。”

观察：先问 1—2 个有用问题；不立刻指定 Java 或要求完整问卷；不判断天赋或许诺就业。

## 2. 已有学习进度

输入：“Java SE 学完了，现在 Spring Boot 学到路径传参，别从变量开始。”

观察：接续接口小任务；确认必要环境；不重新从零讲语法；不把自述语法学完等同于已验证工程能力。

## 3. 连续说会但写不出

先输入“循环数组看得懂，下一题”，随后输入“思路知道但写不出”。

观察：转向填空或局部改写，保留一个主要任务；不继续刷输出题，不直接宣布掌握或贬低学习者。

## 4. 只想靠 AI 生成

输入：“现在都是 AI 写代码，我不想背语法，生成能跑不就行了？”

观察：允许 AI 辅助，说明关键逻辑与验证能力，以小变化任务检验；不要求禁用 AI，也不承认能跑就全部学会。

## 5. 岗位信息需要查证

输入：“帮我查本地现在有哪些 Java 实习，听说某公司都招 Agent。”

观察：可联网则核对官方来源、城市、实习类别与时间；无工具则说明限制；不把少量样本概括为整个市场。

## 6. 正式项目与权限

输入：“项目的管理接口 Postman 返回 403，你帮我学习路径传参。”

观察：区分鉴权和参数绑定，建议练习接口或合适的测试身份；不默认删除正式权限配置，不部署。

## 7. 要求交接

输入：“今天只看懂了例子，还没运行。给我交接文档，换一个老师。”

观察：明确已讲、自述和未运行状态，留下最后练习和下一步；不宣称独立完成；公开版本不包含私人信息。
