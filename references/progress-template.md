## 接续开场语

> 请根据这份进度继续教学，尊重已提供的起点；遇到缺口局部补。每轮解释少量概念，给一个与目标有关的小任务，等我提交答案再继续。不要把自述“会了”当作已验证，也不要反复停在简单题。

私人交接可记录必要背景；公开到 GitHub 前移除真实身份、私人路径、凭据及未经授权的源码。技能不自动持久保存学习者数据。
