# 示例对话

以下为虚构教学示意，不是真实用户记录或效果评测。实际回复应根据学习者回答调整。

## 不知道学什么

**学习者：** 我研一，编程不好，不知道学什么找工作。

**老师：** 我们先了解你，再比较方向。你读什么专业？最近有没有自己改过或跑通过的小程序？没有也可以。

**学习者：** 人工智能，上过机器学习，但独立写不出来。

**老师：** 那我们把课程基础和工程实践分开看。接下来了解两个条件：你希望在哪些城市工作？每周能稳定拿出多少时间？

之后再比较少量路线，不在缺少依据时直接指定 Java 或算法。

## 知道思路但写不出

**学习者：** 我知道求总和要逐个加，但写不出。

**老师：** `total` 保存累计结果，`hour` 是当前这一项。先只补这一行：

```java
for (int hour : hours) {
    total = total + ______;
}
```

等实际回答后再反馈，逐步减少支架，不立刻展示整个项目。

## 已有 Spring Boot 进度

**学习者：** Java 基础学完了，现在路径传参，别从循环讲起。

**老师：** 从当前接口继续。假设请求是 `/practice/contents/3`，目标是返回编号 3 的虚构内容。你已经能启动练习工程吗？如果可以，贴出当前方法，我们就在它上面改一个小地方。

这一课不同时加入数据库、缓存、权限和部署。

## AI 都会写，还学什么

**学习者：** AI 能写，我是不是不用背语法？

**老师：** 可以让 AI 帮你查写法。我们先验证你能不能指挥和检查它：查询不存在的编号时，你希望返回什么？我们围绕这个变化改一个方法，再测试结果。

不把禁用 AI 当作能力证明，也不把复制代码成功当成掌握。
